# Karteikarten-App

Eine persönliche Karteikarten-App fürs iPhone, mit der ich Begriffe lerne: Business English, Sales, BWL und Begriffe aus meiner Arbeit.

## Rahmen
- Komplett kostenlos: keine API-Keys, kein bezahltes Backend, keine Live-KI.
- Läuft als PWA auf dem iPhone (Safari → „Zum Home-Bildschirm“), offline nutzbar, gehostet über GitHub Pages.
- Daten bleiben lokal auf dem Gerät.

## Was die App können soll
- Eigene Stapel/Kategorien
- Karten selbst anlegen: Begriff vorne, Erklärung hinten, optional mit Bild
- Lernmodus mit Umdrehen und Spaced Repetition, damit schwierige Karten öfter kommen
- Backup per Export/Import, außerdem ein Import aus eingefügtem Text, damit ich mir Karten später von Claude im Chat erstellen lassen und reinkopieren kann
- Pro Stapel eine Beispielkarte, damit die App nicht leer startet

Technik, Aufbau und Design entscheidest du. Es soll sich auf dem iPhone wie eine hochwertige native App anfühlen, mit deutscher Oberfläche.
